# QuikBankAccountBalancer — Документация по архитектуре

## 📋 Обзор
Python-приложение (Streamlit) для анализа инвестиционного портфеля, экспортированного из QUIK (брокерский терминал Арка). Приложение состоит из **2 страниц**:

1. **"📊 Анализ"** — визуальный разбор портфеля, сравнение с целями
2. **"🎯 Редактор целей"** — управление целевыми весами инструментов и классов

---

## 📁 Структура файлов
```
QuikBankAccountBalancer/
├── app.py                          # Основной код приложения (~1431 строка)
├── run_app.bat                     # Запуск приложения
├── README.md                       # Это файл
├── targets.json                    # Файл целевых весов (автоматическое сохранение)
├── test_portfolio.txt              # Тестовые данные (фиктивный портфель: акции, ОФЗ, корп. облигации, ETF, золото, фьючерсы, ликвидность)
└── do_not_push/                    # Вспомогательные файлы (не отправляются в гитхаб)
    ├── app — копия.py              # Резервная копия основного кода
    ├── appq.py                     # Дополнительные функции
    └── ...                         # Другие вспомогательные файлы
```

## 📦 Установка зависимостей
1. Установите [QuikPy](https://github.com/cia76/QuikPy) в свой проект
   (копируйте содержимое папки `QuikPy` из исходников или используйте `pip install quikpy`)
2. Убедитесь, что файл `QuikPy/README` содержит инструкции по настройке
3. Приложение использует стандартные библиотеки Python и Streamlit

## 🚫 Исключения
- Папка `do_not_push/` содержит вспомогательные файлы, которые **не должны** попадать в репозиторий
- Библиотека `QuikPy` — сторонняя, её содержимое **не включается** в гитхаб-репозиторий
