# QuikBankAccountBalancer

Анализ инвестиционного портфеля QUIK с возможностью настройки целевых распределений активов.

## Описание

Этот проект позволяет анализировать инвестиционный портфель, созданный в QUIK (система для торговли на фондовых и срочных рынках), и сравнивать его с заданными целевыми распределениями активов. Программа предоставляет интерактивный интерфейс для просмотра текущего состояния портфеля и редактирования целевых показателей.

## Особенности

- Анализ фондового и срочного рынка
- Визуализация распределения активов
- Настройка целевых распределений активов
- Интерактивный интерфейс с помощью Streamlit
- Поддержка различных классов активов (Акции, Облигации, ETF, Фьючерсы и др.)

## Зависимости

- Python 3.12
- Streamlit
- pandas
- plotly
- numpy

## Установка

### Способ 1: Использование run_app.bat (рекомендуемый)

1. Запустите `run_app.bat` двойным кликом или через командную строку
2. Скрипт автоматически установит uv, создаст виртуальное окружение и установит зависимости

### Способ 2: Ручная установка

1. Создайте виртуальное окружение:
   ```
   python -m venv .venv
   ```

2. Активируйте виртуальное окружение:
   - Windows: `.venv\Scripts\activate`
   - Linux/Mac: `source .venv/bin/activate`

3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Настройка QuikPy

Библиотека QuikPy используется для подключения к QUIK. Для её установки необходимо:

1. Скопировать папку со скриптами LUA **QUIK\lua** в папку установки QUIK
2. Скопировать папку **QUIK\socket** в папку установки QUIK
3. Библиотека core.dll для LUA версии 5.4.1 также доступна в проекте QUIK# 
4. Запустите QUIK и в меню **Сервисы** выберите **LUA скрипты**, добавьте и запустите скрипт **QuikSharp.lua**

Если в окне сообщений QUIK выдаст **QUIK# is waiting for client connection...**, то скрипт запущен успешно.

Библиотеку QuikPy можно также установить напрямую с GitHub: https://github.com/cia76/QuikPy

## Запуск

После установки запустите приложение:
```
streamlit run app.py
```

Или используйте `run_app.bat` для автоматической установки и запуска.

## Файлы проекта

- `app.py` - основной файл приложения с интерфейсом Streamlit
- `run_app.bat` - скрипт для автоматического запуска приложения
- `targets.json` - файл с целевыми распределениями активов
- `test_portfolio.txt` - тестовый файл портфеля для демонстрации
- `requirements.txt` - зависимости проекта
- `QuikPy/` - библиотека для работы с QUIK

## Настройка целевых распределений

Целевые распределения задаются в файле `targets.json`:

```json
{
  "classes": {
    "ОФЗ": 20.0,
    "Корп. облигации": 10.0,
    "Акции РФ": 5.0,
    "ETF": 5.0,
    "Золото": 10.0,
    "Фьючерсы": 15.0,
    "Ликвидность": 35.0
  },
  "tickers": {},
  "futures_overlay_classes": [
    "ОФЗ",
    "Корп. облигации",
    "ETF"
  ],
  "futures_buffer_pct": 15.0
}
```
